
# Week 9 - MongoDB Library API

## Description

A Library REST API built with Node.js, Express, MongoDB and Mongoose.

This project is part of the Week 9 backend course assignment.

## Technologies

- Node.js
- Express
- MongoDB
- Mongoose
- Docker
- mongo-express
- Insomnia
- Git and GitHub

## Features

- Book CRUD operations
- Schema validation
- Filtering and sorting
- Pagination
- Authors and references
- Mongoose populate

## Project Structure

- index.js - Express server
- db.js - MongoDB connection
- models/ - Mongoose models
- compose.yml - Docker configuration
- .env.example - Environment variable template
